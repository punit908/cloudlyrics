# CloudLyrics Studio

A Vite + React + TypeScript project packaged from the supplied CloudLyrics Studio component.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy on Vercel

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Root Directory: the folder containing this `package.json`

No environment variables are required by this scaffold.
